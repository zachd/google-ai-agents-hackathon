# Google AI Agents Hackathon

This project is a submission for the Google AI Agents Hackathon.

## Setup

### Prerequisites

- Python 3.9+

### Installation

1.  **Create and activate a virtual environment:**

    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```

2.  **Install dependencies:**

    ```bash
    pip install -r requirements.txt
    ```

3.  **Install the Agent Development Kit (ADK):**

    ```bash
    pip install adk
    ```

## Running the project

To run the ADK server, use the following command:

```bash
make run
```

This will start the web server with the agents.
